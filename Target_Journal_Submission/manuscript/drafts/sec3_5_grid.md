### 3.5 How many checkpoints?

{{FIG:Fig7_ablation_checkpoint_grid|Checkpoint-grid ablation (E3, {{CFG.n_secondary}} splits per data set, elastic net). Cycling saved by the trajectory-calibrated rule for different checkpoint grids, together with the false-pass and false-reject rates; the naive sequential rule is shown for reference. With a single checkpoint all rules coincide.}}

The number of looks trades flexibility against conservativeness ({{FIGREF:Fig7_ablation_checkpoint_grid}}; {{STABREF:tables/T6_ablation_grid.csv}}). Every grid kept both error rates of the trajectory rule below 0.10, whereas the naive sequential rule became more invalid as looks were added: on HUST its false-pass rate rose from {{E3.h.single_100.naive.fpr}} with one checkpoint to {{E3.h.pair_100_1000.naive.fpr}} with two, {{E3.h.sparse_100_300_600_1000.naive.fpr}} with four and {{E3.h.all17.naive.fpr}} with all 17. For efficiency, the dense grids of the main experiment were not optimal. On MATR/CLO a sparse grid of cycles 50, 100, 200 and 300 saved {{E3.mc.sparse_50_100_200_300.proposed.sav}}% of the cycling, against {{E3.mc.all16.proposed.sav}}% with all 16 checkpoints and {{E3.mc.single_50.proposed.sav}}% with the best single checkpoint (cycle 50). On HUST the sparse grid (cycles 100, 300, 600, 1000) saved {{E3.h.sparse_100_300_600_1000.proposed.sav}}% against {{E3.h.all17.proposed.sav}}% with all 17 checkpoints, but a single checkpoint at cycle 300 saved more ({{E3.h.single_300.proposed.sav}}%). Each additional checkpoint raises the calibrated thresholds, because the maximum of more scores is larger; checkpoints that add little information therefore cost efficiency. The best single checkpoint, however, differed between the data sets (cycle 50 for MATR/CLO, cycle 300 for HUST; cycle 100 was a poor choice for HUST, {{E3.h.single_100.proposed.sav}}%), and it cannot be chosen on the calibration cells without voiding the guarantee. A sparse grid of three to five checkpoints spread over the period in which the early-cycle features become informative (Section 3.9) was the most robust choice across both data sets; we report the dense grids in the main experiment because they were fixed before the experiments were run.
