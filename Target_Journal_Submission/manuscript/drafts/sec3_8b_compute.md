**Computational cost.** The screening layer itself is negligible ({{STABREF:tables/T9_compute.csv}}): calibrating the two thresholds took {{E6.mc.calibration_only_n40.cal_ms}} ms for 40 calibration cells and {{E6.mc.calibration_only_n4000.cal_ms}} ms for 4,000, and deciding 1,000 cells over all checkpoints took about {{E6.mc.calibration_only_n4000.decide_ms}} ms on one CPU core. The cost of the procedure is that of training the per-checkpoint base predictors once per calibration campaign: on MATR/CLO, {{E6.mc.en.sec}} s per split for the elastic net (all {{D.mc.M}} checkpoints, including internal cross-validation), {{E6.mc.gp.sec}} s for the Gaussian process, {{E6.mc.cnn.sec}} s for the CNN, and {{E6.mc.rf.sec}} s for the random forest. Peak memory of a process running one split was about {{E6.mc.en.mem}} MB for every model, dominated by the imported numerical libraries. All of this is many orders of magnitude below the cost of one cycling day of a single cell, so computation is not a constraint for deployment in a test laboratory.
